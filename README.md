# Manufacturas y Cortinas Cadena

Primera versión de la página, construida en HTML, CSS y JavaScript, tomando como referencia el diseño de Canva.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: colores, tipografías, distribución y estilos responsive.
- `script.js`: menú móvil, animaciones al desplazarse y envío de solicitud por WhatsApp.
- `assets/`: imágenes proporcionadas para el proyecto.

## Colores de marca
- Azul marino: `#00204A`
- Rojo: `#B80C0E`
- Rojo oscuro: `#B0241E`
- Blanco: `#FFFFFF`

## Cómo previsualizar
Abre `index.html` en un navegador. Para trabajar cómodamente, abre la carpeta completa en Visual Studio Code.
